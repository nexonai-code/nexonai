# 1. When this agreement is needed
NexonAI supplies software and operates no servers. As long as NexonAI has no access to the organisation's systems or data, it normally does not process personal data on the organisation's behalf, and this agreement is not needed. It is concluded before NexonAI installs, maintains or supports unpruuf Compliance on systems where personal data from reports could become visible. If NexonAI never receives access, the declaration in section 12 may be used instead. The template must be reviewed by a lawyer before signing.

# 3. Subject matter and duration

# 4. Nature, purpose and data
| Item | Content |
| Nature of processing | Access to the controller's server or case officer computer during installation, updates and support sessions |
| Purpose | Running the reporting channel; fixing faults |
| Data that may become visible | Case codes, dates, case status; case content only if the controller shows it during a support session |
| Data subjects | Reporters, persons concerned, witnesses, case officers |

# 5. Instructions
The processor processes personal data only on documented instructions from the controller, including this agreement. Support sessions take place through a remote session started and supervised by the controller, or on site. The processor does not copy, export or keep case data.

# 6. Confidentiality
Persons working for the processor are bound to confidentiality. Only persons who need access for the task receive it.

# 7. Security
The processor applies the measures in the annex and in the list of technical and organisational measures of unpruuf Compliance (GDPR Art. 32).

# 8. Sub-processors
The processor uses no sub-processors. Engaging one requires the controller's prior written authorisation.

# 9. Assistance
The processor assists the controller with requests of data subjects (GDPR Art. 12–22), with security, breach notifications, data protection impact assessments and prior consultations (GDPR Art. 32–36), as far as the processor's access allows.

# 10. Breaches
The processor informs the controller without undue delay, and at the latest within 24 hours, after becoming aware of a personal data breach, with the information available at that time.

# 11. End of processing, evidence and audits
At the end of the service the processor deletes any personal data it may hold and confirms this in writing. The processor makes available the information needed to demonstrate compliance with GDPR Art. 28 and allows audits by the controller or an auditor it appoints, with reasonable notice.

# 12. Alternative: declaration of non-access
NexonAI Consulting SRL declares that it operates no server for the controller, has no remote access to the controller's systems, receives no reports, case files or logs and holds no copy of personal data from the reporting channel. Updates are delivered as software packages that the controller installs. If this changes, the parties conclude this data processing agreement first.

# Annex: measures of the processor
- Support only through sessions started and ended by the controller; no permanent remote access.
- No copies of case data on processor devices; no export of case data.
- Work devices of the processor with full-disk encryption, screen lock and current security updates.
- Access data received from the controller stored in an encrypted password manager and deleted after the task.
