# 1. Părți
[Organizația], [sediul], [CUI] („organizația”) și NexonAI Consulting SRL, Alba Iulia („NexonAI”).

# 2. Ce testăm
- Un canal de raportare de test pe un server operat de organizație (un calculator, o mașină virtuală sau un cont de hosting).
- Aplicația responsabilului pe un calculator al organizației.
- Raportări de test, dialog, termene, ștergere și export, create de persoanele de test ale organizației.

# 3. Reguli pentru testare
- Doar raportări de test. În perioada de testare nu se introduc raportări reale și nici date personale ale unor persoane reale.
- Organizația operează serverul. NexonAI nu are acces, cu excepția sesiunilor la distanță pornite și supravegheate de organizație.
- NexonAI pune la dispoziție software-ul, o sesiune de configurare și o sesiune introductivă de aproximativ o oră.

# 4. Durată și cost
- 30 de zile, de la [data de început] până la [data de sfârșit]. Testarea este gratuită.
- Nu există obligația de cumpărare. Oricare parte poate încheia testarea oricând, prin e-mail.

# 5. După testare
- **Continuare:** organizația acceptă oferta; configurarea de test devine canalul activ după ștergerea raportărilor de test.
- **Oprire:** organizația șterge serverul și aplicația responsabilului. NexonAI nu deține date din testare.

# 6. Criterii de reușită convenite pentru această testare
- [ ] O raportare de test din aplicație și una din browser ajung la responsabil.
- [ ] Confirmarea și răspunsul ajung la sesizantul de test.
- [ ] Termenele sunt vizibile; ștergerea și exportul unui caz de test funcționează.
- [ ] Responsabilul cu protecția datelor a primit pachetul de dovezi.

# 7. Stare
unpruuf Compliance este testat; nu este auditat independent și nu este certificat. Software-ul de test este pus la dispoziție ca atare.
