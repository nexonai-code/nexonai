# 1. Parties
[Organisation], [registered office], [CUI] ("organisation") and NexonAI Consulting SRL, Alba Iulia ("NexonAI").

# 2. What we test
- A test reporting channel on a server operated by the organisation (a computer, a virtual machine or a hosting account).
- The case officer app on a computer of the organisation.
- Test reports, dialogue, deadlines, deletion and export, made up by the organisation's test persons.

# 3. Rules for the trial
- Only test reports. No real reports and no personal data of real persons are entered during the trial.
- The organisation operates the server. NexonAI has no access, except in remote sessions that the organisation starts and supervises.
- NexonAI provides the software, a setup session and one introductory session of about one hour.

# 4. Duration and cost
- 30 days from [start date] to [end date]. The trial is free of charge.
- There is no obligation to buy. Either party may end the trial at any time by e-mail.

# 5. After the trial
- **Continue:** the organisation accepts the offer; the test setup becomes the live channel after the test reports are deleted.
- **Stop:** the organisation deletes the server and the case officer app. NexonAI holds no data from the trial.

# 6. Success criteria agreed for this trial
- [ ] A test report from the app and one from the browser reach the case officer.
- [ ] Acknowledgement and reply reach the test reporter.
- [ ] Deadlines are visible; deleting and exporting a test case work.
- [ ] The data protection officer has received the evidence pack.

# 7. Status
unpruuf Compliance is tested; it is not independently audited and not certified. The trial software is provided as is.
