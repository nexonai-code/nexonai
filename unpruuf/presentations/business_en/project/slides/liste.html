Server lists

You decide which servers carry which contacts

Import a list

The server saves its addresses as a file. The app imports it as a list, for example per customer or site.

Choose a list

When adding a contact you choose a list. The app picks 3 nodes from it automatically.

Several servers per list

If a list holds several servers, the three nodes of a contact have different operators.

This way it is always traceable which servers carry which contact.
