Server-Listen

Sie bestimmen, welche Server welche Kontakte tragen

Liste importieren

Der Server speichert seine Adressen als Datei. Die App importiert sie als Liste, zum Beispiel pro Kunde oder Standort.

Liste wählen

Beim Hinzufügen eines Kontakts wählen Sie eine Liste. Die App sucht daraus automatisch 3 Nodes aus.

Mehrere Server pro Liste

Liegen mehrere Server in einer Liste, haben die drei Nodes eines Kontakts verschiedene Betreiber.

So ist jederzeit nachvollziehbar, welche Server welchen Kontakt tragen.
