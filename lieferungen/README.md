Regeln:
- Dateiname mit Datum und Version, z. B. `unpruuf_Whitepaper_2026-10-25_v7.zip`. Eine neue Version ersetzt die alte im selben Ordner.
- Dateien über 50 MB kommen nicht ins Repo (GitHub-Grenze), sie liegen nur in Drive. Unten aufgeführt.
- Nichts mit dem alten Namen „safeline“.
